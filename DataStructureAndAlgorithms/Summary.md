### The Core Concept
    1. DataStructure Keywords: Traversal and Access
        Core Actions: insert, delete, search, update
        The right data structure helps you quickly and easily look up or modify elements.
    2. Algorithm Keywords: Brute-force, Time Complexity, Space Complexity
        All algorithms come from brute-force.
        Core Actions: optimize time complexity, optimize Space complexity
        Using cache or eliminating repeated work reduces extra time and space overhead.
